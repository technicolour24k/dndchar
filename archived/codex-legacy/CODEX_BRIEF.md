# dndchar / Character Sheet Redesign Codex Brief

## Goal
Modernise the current character sheet into a clearer, more usable D&D 5e character management interface while preserving existing functionality.

## Current Problem
The existing page exposes too many raw fields and controls at once. It works, but it is visually dense and difficult to use during play.

## Desired Direction
Use the Uizard mockups (available in the [mockups](./mockups/) folder) as design inspiration.


## Must Keep
Existing character data, save/load behaviour, dice rolling, equipment attacks, helper calculations, and D&D 5e 2014 support.

## New Features
Autosave, full version history, latest three version previews, full version history page, restore, duplicate from version, and session/level-up snapshots.

## Implementation Rules
Inspect the current repo before making changes. Make small, reviewable commits. Do not introduce large frameworks unless requested. Prefer plain PHP, JS, CSS, and MySQL-compatible changes.
